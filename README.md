# Поиск поставщиков · модуль закупок

Прототип сервиса, который помогает ресторану найти и выбрать поставщика продуктов: ингредиентов, готовой продукции, упаковки.

**Демо:** https://procure-lab-9olgt.vercel.app

## Что умеет

- Поиск по товару («мука высшего сорта», «куриное филе») в выбранном городе.
- Компании подбираются через API 2ГИС по рубрикам справочника — в выдачу попадают только организации с подходящей рубрикой. Филиалы одной сети склеиваются, администрации, кафе и рестораны отсекаются.
- Обогащение с сайтов: сервис находит сайт каждой компании через Яндекс Поиск, проверяет, что сайт действительно её, и собирает контакты, товары с ценой, фасовкой и фото (Tilda Store, schema.org, карточки в вёрстке), минимальный заказ и условия доставки. У каждого факта — ссылка на источник.
- Оценка совпадения 0–100 с объяснением: профиль (опт или розница), рубрика, репутация, найденная позиция и цена на сайте, режим работы.
- Карточка компании, сравнение до 4 поставщиков, письмо из карточки (почта, WhatsApp, шаблоны КП), внесение ответа поставщика.
- «Избранное» — канбан со статусами до «Постоянный / Резервный», вкладка «Мои поставщики» по категориям.
- Фильтры, сортировка, скрытие компаний, отметка просмотренных.

## Архитектура

```
Браузер ──► Vercel /api/search, /api/count ──► 2ГИС Places API 3.0
        └─► Vercel /api/enrich ──► Yandex Cloud Function ──► Яндекс Поиск + сайты поставщиков
```

Краулер работает в Yandex Cloud, потому что российские сайты массово блокируют зарубежные дата-центры.

| Путь | Что это |
|---|---|
| `src/app.html` | Интерфейс (HTML + CSS + JavaScript без фреймворков) |
| `build.mjs` | Собирает `public/index.html` из `src/app.html` |
| `api/*.mjs` | Vercel Functions: поиск, счётчики, обогащение, ЕГРЮЛ |
| `lib/twogis.mjs` | Прокси к 2ГИС: регионы, нормализация, кэш, повторы |
| `lib/enrich.mjs` | Краулер: поиск сайта, проверка владельца, извлечение товаров и условий |
| `lib/netguard.mjs` | Защита от SSRF |
| `lib/guard.mjs` | Проверка источника запроса, лимиты, LRU-кэш |
| `yc/index.mjs` | Обёртка краулера для Yandex Cloud Functions |
| `server.mjs` | Локальный запуск |

## Запуск

Нужен Node 18+.

```
node build.mjs
TWOGIS_KEY=... SEARCH_API_KEY=... FOLDER_ID=... node server.mjs
# http://localhost:8787
```

### Переменные окружения

| Где | Переменная | Назначение |
|---|---|---|
| Vercel | `TWOGIS_KEY` | Ключ 2ГИС Places API |
| Vercel | `YC_ENRICH_URL`, `YC_ENRICH_TOKEN` | Адрес функции в Yandex Cloud и общий секрет |
| Yandex Cloud Function | `SEARCH_API_KEY`, `FOLDER_ID` | Яндекс Поиск (поиск сайтов компаний) |
| Yandex Cloud Function | `TOKEN` | Тот же секрет, что `YC_ENRICH_TOKEN` |

### Деплой

- Vercel: `npx vercel deploy --prod` (функции в регионе fra1).
- Yandex Cloud: собрать `npx esbuild yc/index.mjs --bundle --platform=node --target=node18 --format=cjs --outfile=yc/dist/index.js` и загрузить `yc/dist` как версию функции (runtime nodejs18, entrypoint `index.handler`).

## Ограничения

- На бесплатном ключе 2ГИС не отдаёт телефоны и сайты — их находит краулер. Лимит: 10 организаций на страницу, до 5 страниц.
- Минимальный заказ и цены есть далеко не на всех сайтах — основной путь для них запрос КП.
- Состояние (избранное, заметки, КП) хранится в браузере; базы данных в прототипе нет.

# Безопасность: аудит и исправления

Архитектура: браузер → Vercel (`/api/*`) → 2ГИС Places API / Yandex Cloud Function (краулер) → сайты поставщиков.

## Исправлено

| Риск | Уровень | Что было | Что сделано |
|---|---|---|---|
| SSRF в краулере | Критичный | Параметр `site` позволял функции в Yandex Cloud ходить на любые адреса, включая сервис метаданных `169.254.169.254` (проверено: функция получала ответ) | `lib/netguard.mjs`: только `http(s)`, порты 80/443, запрет приватных/служебных IP после DNS-резолва, каждый редирект проверяется заново |
| Открытый API, расход квот | Высокий | Любой мог вызывать `/api/search`, `/api/enrich` скриптом — выжигая лимит 2ГИС (ключ уже блокировался) и платный Яндекс Поиск | Проверка источника (`Sec-Fetch-Site` / Origin / Referer), лимиты на IP: поиск 40/мин, счётчики 30/мин, обогащение 30/мин, ЕГРЮЛ 10/мин |
| XSS через данные чужих сайтов | Средний | Ссылки и картинки с сайтов поставщиков могли содержать `javascript:` | Санитизация URL на сервере (`safeHttpUrl`) и в браузере (`safeUrl`), экранирование полей ЕГРЮЛ |
| Нет заголовков безопасности | Средний | Только HSTS | CSP, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`, `COOP` |
| Неограниченные входные данные | Средний | Длина параметров не ограничена, кэш в памяти без лимита | Обрезка параметров, whitelist полей, LRU-кэш (800/400 записей) |
| Утечка внутренних ошибок | Низкий | Ответы содержали тексты ошибок апстримов | Пользователю — общие сообщения, детали — в логи |
| Сравнение токена функции | Низкий | `!==` | `timingSafeEqual` |
| Этика обхода сайтов | — | robots.txt не учитывался | Сайты с `Disallow: /` не обходятся; лимит размера страницы 5 МБ |

## Остаётся (для продакшена)

1. **Ротация секретов.** В переписке побывали: ключи 2ГИС (старый и текущий), авторизованный ключ сервисного аккаунта `claude-deploy`, OAuth-токен Яндекса, секрет OAuth-приложения Netlify. Перевыпустить и удалить старые.
2. **Наименьшие привилегии.** Сервисному аккаунту `claude-deploy` после деплоя снять роль `editor`; функции сервисный аккаунт не нужен.
3. **Распределённый rate limit.** Сейчас лимиты в памяти инстанса Vercel — защищают от простого скрипта, но не от распределённой атаки. В проде: Upstash Redis / Vercel WAF.
4. **Бюджет.** В Yandex Cloud включить уведомления биллинга и лимит параллельных вызовов функции.
5. **CSP без `unsafe-inline`.** Вынести скрипт и обработчики в отдельный файл, перейти на nonce/hash.
6. **Данные пользователей.** Заметки, контакты, КП хранятся в `localStorage` браузера — без авторизации и шифрования. В продукте — бэкенд с авторизацией (SSO основной платформы), разграничением по подразделениям и аудитом.
7. **Юридическое.** Обход сайтов — только публичные страницы с учётом robots.txt; для коммерческой эксплуатации — договор с 2ГИС и проверка условий использования данных.
